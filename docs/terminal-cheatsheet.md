# ターミナル開発 早見表

VS Code の代わりに tmux + Neovim + lazygit で開発する時の操作まとめ。
このリポジトリのスクリプトで入る設定が前提（`bash install-all.sh` 済み、または devcontainer の dotfiles 経由）。

- 表記: `C-b` = Ctrl+b、`<leader>` = Space キー、`S-Tab` = Shift+Tab
- 迷ったら: ファイルツリー・差分画面では `g?`、lazygit では `?` でその画面のキー一覧が出る

## 基本の流れ（Claude Code と並行で作業する時）

1. tmux を起動（`tmux`、devcontainer CLI なら `scripts/devcontainer-up.sh` で入った時点で tmux の中）
2. `C-b |` で左右に分割し、片方で `claude`、もう片方で `nvim .`
3. Claude の作業が終わったら `C-b g` で lazygit を開いて差分を確認 → stage → commit
4. 細かく読みたい時は nvim で `<leader>gd`（VS Code の Source Control と同じ、左右並びの差分）

| やりたいこと | 操作 |
|---|---|
| Claude が今変えた内容を見る | `C-b g`（lazygit）、または nvim で `<leader>gd` |
| コミット履歴とその差分を見る（Git Graph 相当） | lazygit で `4` → コミットで `Enter` → ファイルを選ぶ |
| ファイルを名前で開く（VS Code の Ctrl+P） | nvim で `C-p` |
| プロジェクト内を文字列検索（VS Code の Ctrl+Shift+F） | nvim で `<leader>fg` |
| Markdown を読む | nvim で開けば整形表示。画像も見たい時は `<leader>mp`（ブラウザ） |
| Markdown をさっと見る（nvim を開かずに） | `glow README.md` |

## tmux

prefix は `C-b`（押して離してから次のキー）。マウスでペイン選択・リサイズ・スクロールもできる。

| 操作 | キー |
|---|---|
| 左右に分割 / 上下に分割 | `C-b \|` / `C-b -` |
| ペインを移動 | `C-b 矢印キー`（またはマウスでクリック） |
| ペインを最大化 / 戻す | `C-b z` |
| ペインを閉じる | `C-b x`（またはそのペインで `exit`） |
| **lazygit を popup で開く** | `C-b g`（`q` で閉じる） |
| 新しいウィンドウ（タブ相当） / 次 / 前 / 一覧 | `C-b c` / `C-b n` / `C-b p` / `C-b w` |
| スクロール（コピーモード） | `C-b [`（`q` で抜ける）。マウスホイールでも可 |
| 範囲選択してクリップボードにコピー | マウスでドラッグ（ダブルクリックで単語、トリプルクリックで行）。離した時点でコピーされ、他のアプリに `Ctrl+V` で貼れる |
| tmux から抜ける（裏で動かしたまま） / 戻る | `C-b d` / `tmux attach` |
| 設定の再読み込み | `C-b r` |

## Neovim

### Vim の最低限

| 操作 | キー |
|---|---|
| 入力モードへ / 抜ける | `i` / `Esc` |
| 保存 / 閉じる / 保存して閉じる / 保存せず閉じる | `:w` / `:q` / `:wq` / `:q!` |
| 元に戻す / やり直す | `u` / `C-r` |
| ファイル内検索 / 次 / 前 | `/文字列` → `Enter` / `n` / `N` |
| ウィンドウ（分割）間を移動 | `C-w` → `h` `j` `k` `l`（またはマウスでクリック） |

### ファイルを開く・探す

| 操作 | キー |
|---|---|
| ファイル名で検索して開く | `C-p`（または `<leader>ff`） |
| 文字列で検索 | `<leader>fg` |
| 開いているファイル一覧 / 最近開いたファイル | `<leader>fb` / `<leader>fr` |
| ファイルツリーの開閉 / 今のファイルをツリーで表示 | `<leader>e` / `<leader>E` |

検索画面（telescope）では、文字を打って絞り込み → `C-n` `C-p`（または矢印）で選択 → `Enter` で開く → `Esc` `Esc` で閉じる。

ファイルツリー（nvim-tree）の中:

| 操作 | キー |
|---|---|
| 開く / 縦分割で開く | `Enter` / `C-v` |
| 新規作成（末尾を `/` にするとフォルダ） / 削除 / 名前変更 | `a` / `d` / `r` |
| コピー / 切り取り / 貼り付け | `c` / `x` / `p` |
| 全部閉じる / 再読み込み / 閉じる / ヘルプ | `W` / `R` / `q` / `g?` |

### Git（差分・履歴）

| 操作 | キー |
|---|---|
| **作業中の変更を一覧と差分で見る**（Source Control 相当） | `<leader>gd` |
| **コミット履歴（リポジトリ全体）** | `<leader>gh` |
| コミット履歴（今のファイルだけ） | `<leader>gf` |
| 差分画面を閉じる | `<leader>gq` |

差分画面（diffview）の中:

| 操作 | キー |
|---|---|
| 次のファイル / 前のファイル | `Tab` / `S-Tab` |
| 選んだファイル・コミットの差分を開く | `Enter` |
| stage / unstage の切り替え（作業中の変更の画面） | `-` |
| 全部 stage / 全部 unstage | `S` / `U` |
| コミットの詳細を見る（履歴の画面） | `L` |
| そのファイルを編集用に開く | `gf` |
| ヘルプ | `g?` |

普通にファイルを開いている時（gitsigns）:

| 操作 | キー |
|---|---|
| 次の変更箇所 / 前の変更箇所 | `]c` / `[c` |
| 変更箇所の差分をポップアップで見る | `<leader>hp` |
| 変更箇所を元に戻す | `<leader>hr` |
| この行を誰がいつ変えたか（blame） | `<leader>hb` |

行番号の左の印: `┃` 追加・変更、`▁` `▔` 削除、`~` 変更して削除、`┆` git 未管理のファイル。

### Markdown

| 操作 | キー |
|---|---|
| 整形表示の ON / OFF（`.md` を開くと自動で ON） | `<leader>mr` |
| ブラウザでプレビュー（画像・Mermaid も表示） / 閉じる | `<leader>mp`（もう一度押すと閉じる） |

- プレビューは `http://localhost:8090/page/1`。ブラウザが無い環境（devcontainer）では URL が表示されるので手元のブラウザで開く（VS Code 経由ならポートは自動転送）
- 別の nvim で同時にプレビューするとポートがぶつかる。その時は `MKDP_PORT=8091 nvim` で起動

## lazygit

起動は `C-b g`（tmux）または `lazygit`。マウスでのクリック・スクロールも使える。

画面は左に 5 つのパネル、右が差分などの表示。数字キーでパネルへ移動:
`1` 状態 / `2` ファイル（変更） / `3` ブランチ / `4` コミット（グラフ） / `5` stash

| 操作 | キー |
|---|---|
| 上下に移動 / パネル移動 | `↑` `↓`（`k` `j`） / `←` `→`（`h` `l`）または数字キー |
| 中に入る（コミット → ファイル一覧など） / 戻る | `Enter` / `Esc` |
| 右の差分をスクロール | `C-u` / `C-d`（または `PgUp` / `PgDn`） |
| stage / unstage（ファイルパネル） / 全部 stage | `Space` / `a` |
| 変更を破棄（ファイルパネル） | `d` |
| コミット / 直前のコミットに追加（amend） | `c` / `A` |
| push / pull | `P` / `p` |
| ファイルを nvim で開く | `e` |
| 差分の表示を切り替え（delta ⇔ git 標準） | `\|` |
| 直前の操作を取り消す | `z` |
| **キー一覧（迷ったらこれ）** / 終了 | `?` / `q` |

## ターミナルのコマンド

| コマンド | 内容 |
|---|---|
| `glow README.md` | Markdown を整形して表示（長い時は `glow -p README.md` でページ送り） |
| `glow` | カレントディレクトリの Markdown を一覧から選んで読む |
| `rg 文字列` | ファイルの中身を検索（ripgrep。`.gitignore` の対象は除外される） |
| `fd 名前` | ファイル名で検索 |
| `fzf` | 一覧からあいまい検索で選ぶ（例: `nvim $(fzf)`） |

## devcontainer で使う

- VS Code で開く: 何もしなくてよい（ユーザー設定の dotfiles でコンテナ作成時に自動導入される）
- VS Code を使わない: プロジェクトのディレクトリで `bash ~/tools/git/development-setting-napa/scripts/devcontainer-up.sh`
- 設定を変えたら GitHub に push してからコンテナをリビルドすると反映される
